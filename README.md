# Prathamesh — Developer Portfolio

A cinematic, dark, recruiter-focused portfolio built with Next.js, React, and TypeScript. The visual direction takes inspiration from the atmospheric pacing and scroll-led storytelling in the SELENE reference, while using original portfolio content and CSS-generated artwork.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Before publishing

- Replace the placeholder email address `hello@prathamesh.dev` with a verified contact address.
- Confirm the availability status and project status labels.
- Add verified education, work experience, certifications, and other professional links when available.
- Review project descriptions as the repositories evolve.

## Stack

- Next.js App Router
- React + TypeScript
- Custom responsive CSS
- Lucide icons
- Google Fonts (DM Sans, DM Mono, Playfair Display)

No external image assets are required; the visual atmosphere is built with CSS.
